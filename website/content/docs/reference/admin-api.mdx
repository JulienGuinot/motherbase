Every table below is **generated** from the decorators in
`apps/server/controllers/*.controller.ts`: the backend's `npm run docs:routes` writes
`docs/admin-routes.md`, and this repo's `npm run docs:sync` splices that file between
the markers below. `apps/server/tests/route-manifest.unit.test.ts` fails the backend
build when the committed table no longer matches the code. Base paths declared as constants — the
`HTTP_ROUTES.*` ones behind `/rest/v1`, `/api/edge`, `/api/files` and
`/realtime/v1/api/broadcast` — are resolved, so every path here is one you can call.

Routes are mounted automatically by `awilix-express`'s `loadControllers`, so this is the
whole controller surface. Auth routes (`/api/auth/*`) are owned by Better Auth and are not
in this table — see [Auth](/docs/platform/auth/). A handful of endpoints are mounted
directly in `app.ts` and are listed under [Outside the controllers](#outside-the-controllers).

Guards are the `@before(...)` chain, in order. `adminOnly` means `adminGuard`: a valid `X-Platform-Token`, or a session whose role is `ADMIN`. See [request lifecycle](/docs/architecture/request-lifecycle/).

Every response uses the shared envelope from `helpers/api-response.helper.ts`; errors use the shape described in the [error reference](/docs/reference/errors/).

## Notes on specific surfaces

The table above is generated from the controller decorators and is spliced in by
`npm run docs:sync`. Anything written inside those markers is overwritten on the
next sync, so per-route commentary belongs here instead. A note that belongs to a
whole section goes in the backend's `SECTION_NOTES` (`apps/server/lib/route-docs.ts`),
which is where its heading already lives.

### API keys and database connection

`/api/admin/api-keys` and `/api/admin/database/connection` are mapped to the
`secrets.manage` capability in the Console proxy: the first returns a freshly
minted key on create, the second returns the database password. `GET /api/admin/api-keys`
also mints the default publishable key on first read, so a project that predates
the feature shows a usable key rather than an empty table. See
[API Keys](/docs/platform/api-keys/).

### `/api/auth/admin/*`

Guarded by `secretKeyOnly`: a valid **secret** project API key in the `apikey`
header, and nothing else — not an operator session, not a publishable key. This is
the `client.auth.admin` namespace in the SDK, and it is deliberately the only
surface a secret key opens besides the data plane. The Studio admin API above,
which runs SQL, DDL and backups, keeps its own operator authentication.

`listUsers` takes `page` and `per_page`, capped at 1000 rows. `updateUserById`
routes password and role changes to their own guarded methods rather than merging
them into one write: the profile patch refuses to write `role` on purpose, and
going around that would reopen the escalation path that allowlist exists to close.
`invite` does not echo the temporary password back — it has already gone out by
email, and returning it would put a live credential in the caller's logs.

## Outside the controllers

These are mounted directly in `apps/server/app.ts` rather than by a controller, so they
carry no `@before` chain:

| Method | Path | What it is | Guards |
|---|---|---|---|
| `GET` | `/` | Service descriptor: `{ name, docs, health }` | none |
| `GET` | `/api/health-check` | `200 { message, status, db: "connected" }`, or `503 { …, db: "disconnected" }` when `SELECT 1` fails | none |
| `GET` | `/api/docs` | Swagger UI over the generated OpenAPI document | none |
| `ALL` | `/api/auth/*` | The whole Better Auth surface, mounted as one handler before the body parsers | `authLimiter` on credential endpoints, then Better Auth's own |
| `GET` | `/docs/sdk.md` | `docs/sdk.md` from the working directory, as raw Markdown. The Docker image does not ship `docs/`, so in a container it answers `404` | none |
| `GET` | `/<public-bucket>/*` | Static files for the public storage bucket, local driver only | none |

`/api/health-check` and `/api/docs` are unauthenticated by design; `/api/docs` describes
routes but exposes no data. Block both at the edge if you do not want them public — see
[Traefik and TLS](/docs/self-hosting/traefik-and-tls/).

A project API does not serve Project Studio. Studio is mounted by the Platform Console
(`apps/server/console/server.ts`) at `/studio`, which reaches each project's admin routes
through the Console proxy; there, `/console/*` and any other unmatched path `308`-redirect
under `/studio`.

`GET /` answers with a small service descriptor naming the two paths a prober actually
wants, and deliberately no version:

```json
{ "name": "Motherbase API", "docs": "/api/docs", "health": "/api/health-check" }
```
